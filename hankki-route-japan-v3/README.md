# 한끼루트 일본

관광지나 방문 예정 장소를 기준으로 근처 일본 식당을 찾고, 음식 중심 일정표까지 바로 짤 수 있게 만든 간단한 여행자용 웹앱입니다.

## 이번 버전에서 바뀐 점

- 검색 결과가 너무 적게 나오는 문제를 줄이기 위해 검색을 여러 번 나눠서 합치는 방식으로 보강했습니다.
- `오마카세`, `치킨난반`, `규카츠`처럼 세부 키워드를 넣었을 때 비슷한 음식군까지 함께 확장 검색합니다.
- 일정표 추가 시 아침 / 점심 / 저녁 시간대를 각각 아래 기준으로 검사합니다.
  - 아침: `05:00 ~ 11:00`
  - 점심: `11:00 ~ 15:00`
  - 저녁: `17:00 ~ 22:30`
- 휴무일 문자열도 한국어 / 일본어 표현을 같이 검사하도록 보강했습니다.
- 여행 시작일을 입력하면 Day 1, Day 2가 그 날짜 기준으로 계산됩니다.
- UI를 조금 더 서비스형 화면처럼 정리했습니다.

## 실행 방법

### 1) `.env` 파일 만들기

`server.js`와 같은 폴더에 `.env` 파일을 만들고 아래처럼 넣어 주세요.

```env
HOTPEPPER_API_KEY=여기에_발급받은_키
PORT=3000
```

### 2) 실행

Node.js 18 이상에서 아래처럼 실행합니다.

```bash
node server.js
```

브라우저에서 아래 주소를 열면 됩니다.

```text
http://localhost:3000
```

## 무료 배포 추천

현재 구조는 `server.js`가 직접 웹 서버를 띄우는 형태라서, 정적 사이트보다 **Render Web Service**에 올리는 편이 제일 간단합니다.

### Render로 올리는 순서

1. GitHub에 이 프로젝트를 업로드합니다.
2. Render에서 새 **Web Service**를 만듭니다.
3. 저장소를 연결합니다.
4. 환경변수에 아래를 넣습니다.

```text
HOTPEPPER_API_KEY=발급받은_키
```

5. Start Command를 아래로 설정합니다.

```text
npm start
```

6. 배포가 끝나면 Render가 웹 주소를 만들어 줍니다.
