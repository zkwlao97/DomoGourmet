관광지나 내가 갈 장소, 숙소를 기준으로 근처 식당을 모으고, 여행자 관점에서 이동 거리와 식사 시간대를 함께 정리합니다. Hot Pepper 공식 API 기반 식당과 관리자 직접 등록 식당을 함께 다루고, Gemini가 연결되어 있으면 번역과 일정 설명을 더 자연스럽게 보정합니다.

연결 확인 중 Google Maps 링크 기준점 지원 지역별 관리자 추천 숙소 기준 일정 동선 수동 식당 등록

연결 상태를 확인하는 중입니다.

추천 흐름 지역 → 기준 장소 / 숙소 → 음식 또는 식당명 → 결과 비교 → 일정표

검색 결과는 음식 정확 일치와 동선 추천으로 나눠 보고, 일정표에서는 숙소 기준 이동 링크까지 함께 확인할 수 있습니다.

검색 예시 예: 도쿄 · 센소지 · 오코노미야키

음식명뿐 아니라 식당명을 직접 넣어 검색할 수 있습니다. 기준 장소가 잘 안 잡히면 Google Maps 링크를 붙여넣어 좌표를 바로 기준점으로 쓸 수 있습니다.
