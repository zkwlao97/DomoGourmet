# 한끼루트 일본 v4

관광지나 방문 예정 장소를 기준으로 근처 일본 식당을 찾고, 음식 중심 일정표까지 바로 짤 수 있게 만든 여행자용 웹앱입니다.

## 이번 버전에서 바뀐 점

- 검색 결과를 **페이지 단위**로 나눠서 보도록 바꿨습니다.
- `맛집 찾기`와 `내 일정표`를 **분리된 화면처럼 전환**해서 볼 수 있게 바꿨습니다.
- 기준 장소가 잘 안 잡히면 **Google Maps 링크를 붙여넣어 좌표를 기준점으로 잡을 수 있게** 추가했습니다.
- 거리 외에 **도보 추정 시간**도 같이 보여주도록 보강했습니다.
- 일정 자동 채우기를 단순 순서 채우기가 아니라 **추천 규칙 기반 자동 배치**로 바꿨습니다.
- 아침 / 점심 / 저녁 시간대 검증을 더 보수적으로 바꿨습니다.
  - 아침: `05:00 ~ 11:00`
  - 점심: `11:00 ~ 15:00`
  - 저녁: `17:00 ~ 22:30`
- 심야 영업처럼 **자정을 넘기는 영업시간**도 좀 더 정확하게 판정하도록 보강했습니다.

## 실행 방법

### 1) `.env` 파일 만들기

`server.js`와 같은 폴더에 `.env` 파일을 만들고 아래처럼 넣어 주세요.

```env
HOTPEPPER_API_KEY=여기에_발급받은_키
PORT=3000
```

### 2) 실행

Node.js 18 이상에서 아래처럼 실행합니다.

```bash
npm start
```

또는

```bash
node server.js
```

브라우저에서 아래 주소를 열면 됩니다.

```text
http://localhost:3000
```

## 무료 배포 추천

현재 구조는 `server.js`가 직접 웹 서버를 띄우는 형태라서, 정적 사이트보다 **Render Web Service**에 올리는 편이 제일 간단합니다.

### Render로 올리는 순서

1. GitHub에 이 프로젝트를 업로드합니다.
2. Render에서 새 **Web Service**를 만듭니다.
3. 저장소를 연결합니다.
4. 환경변수에 아래를 넣습니다.

```text
HOTPEPPER_API_KEY=발급받은_키
```

5. Start Command를 아래로 설정합니다.

```text
npm start
```

6. 배포가 끝나면 Render가 웹 주소를 만들어 줍니다.

## 참고

- 무료 버전은 실제 리뷰 본문을 수집하지 않습니다.
- 좋은 점 / 주의할 점은 Hot Pepper 구조화 정보와 운영 정보를 바탕으로 정리합니다.
- Google Maps는 길찾기 버튼과 기준점 보정용 링크 입력에만 사용합니다.
- AI 없이도 추천 일정은 동작합니다. 나중에 설명 문장을 더 자연스럽게 만들고 싶을 때만 Gemini API를 붙이면 됩니다.
